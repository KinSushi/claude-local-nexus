Agent Contracts

Chaque agent spécialisé devrait avoir un contrat :

agent:
  id: coding-agent

  objective:
    implement_and_validate_code: true

  allowed_tools:
    - filesystem.read
    - filesystem.write
    - shell.execute
    - git.diff

  forbidden_tools:
    - database.delete
    - credential.rotate

  preferred_models:
    - qwen3-coder-30b-local
    - claude-sonnet-5

  output_schema:
    type: object
    required:
      - summary
      - files_changed
      - tests
      - result

Ça permet ensuite d'empêcher un agent spécialisé de devenir un agent omnipotent.

CONFRONTATION AUX DEUX OUVRAGES - CONCORDANCE. *Design Multi-Agent AI Systems

(references/livres/epub, fragment offset 15646148, 1955 o) recommande
exactement les mecanismes qu'un contrat d'agent devrait exposer et que ce
fichier ne detaille pas : validation de schema, mode dry-run pour toute
operation destructive, confirmation explicite pour les operations a fort
enjeu, et limitation du nombre d'appels a un meme outil. Citation VERIFIEE
verbatim par lecture directe du fragment (`seek`+`read`) :

    "Rate limiting and circuit breakers: Prevent runaway tool use by
    limiting how many times a tool can be called within a time window.
    If an agent calls the same tool 50 times in a minute, something is
    wrong. It should halt execution and alert the human who will
    investigate."
